# Roadmap

## Near Term

1. Re-add GitHub Actions CI after a token with `workflow` scope is available
2. Add a stable `--output` file option
3. Add more tests for mixed-language repositories
4. Improve report wording for first-time maintainers
5. Add documentation examples from real public repositories

## Codex/API Experiments

1. Generate release-readiness summaries from scanner output
2. Suggest issue labels and next actions from repository gaps
3. Explain security-policy and governance gaps in maintainer-friendly language
4. Prototype opt-in PR review notes for maintenance signals

## Later

1. GitHub API mode for issue and pull request freshness
2. SARIF output
3. GitHub Actions annotations
4. Ecosystem-specific checks for Python, JavaScript, Rust, and Go

## Non-Goals For Now

- Replacing security scanners
- Claiming a repository is objectively healthy from one score
- Uploading private source code by default
