# Documentation Index

This directory stores the project memory for `maintainer-scout`.

## Core Docs

- `current-state.md`: what the project can do today
- `roadmap.md`: planned product and maintenance direction
- `sprints/`: larger work plans and implementation logs
- `codex-oss-application-notes.md`: notes for OSS support applications

## Maintenance Rule

When a change affects user-facing behavior, update the relevant doc in the same pull request or commit.
